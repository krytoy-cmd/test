# Alisa Rockets (v1.1.0)

Мод для Minecraft **1.20.1 / Forge**.

## Что нового в 1.1.0
- **Звук запуска** у ракет, РПГ и станции, шипение в полёте.
- **Царь-бомба стала мощнее**: кратер радиусом 22 блока + кольцо вторичных взрывов,
  ударная волна (до 200 урона и разброс сущностей в радиусе 48), сплошной огонь по кратеру,
  10 молний и грибовидное облако из частиц.
- **Ракета стала мощнее**: взрыв радиусом 10 (было 8) + поджог поверхности вокруг эпицентра.

## Содержимое
- Ракета — снаряд, летит по взгляду, взрыв радиусом 10 с огнём.
- Царь-бомба — эпическая ракета с ядерным эффектом.
- РПГ — стреляет ракетами, расходует ракетный заряд, 128 использований.
- Ракетный заряд — боеприпас для РПГ.
- Ракетная станция — ПКМ с ракетой или Царь-бомбой в руке: вертикальный запуск.

## Рецепты
- Ракетный заряд: железо + порох + редстоун (выход 2).
- Ракета: 2 заряда + бумага.
- Царь-бомба: ТНТ сверху, ракета в центре, золотой блок снизу.
- РПГ: 3 железных слитка + заряд (бесформенно).
- Станция: ракета сверху, 5 обсидиана (по углам и в центре нижнего ряда).

## Сборка
1. Установи JDK 17.
2. Скачай Forge MDK 1.20.1 с https://files.minecraftforge.net и распакуй.
3. Скопируй содержимое `src` из этого архива в `src` MDK с заменой,
   а также `build.gradle`, `gradle.properties`, `settings.gradle`.
4. `gradlew.bat build` (Linux/macOS: `./gradlew build`).
5. Готовый jar: `build/libs/alisa-rockets-1.1.0.jar` — в папку `mods`.
